## Selected project

A support ticket platform for customers, support agents, and administrators, built with **Next.js, ASP.NET Core, and PostgreSQL**.

The project brings together role-based ticket workflows, Elasticsearch search, private attachments, and background processing. Engineering decisions include a modular monolith, a transactional outbox, generated API contracts, and automated unit, integration, and browser tests.
