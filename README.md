## Featured project: TicketFlow

[TicketFlow](https://github.com/EhsanEbneKhodadad/ticketflow) is a full-stack support ticket platform for customers, support agents, and administrators. Built as a monorepo with a **Next.js** frontend, an **ASP.NET Core** modular monolith, and a separate background worker.

![TicketFlow support inbox showing tickets and filters](https://raw.githubusercontent.com/EhsanEbneKhodadad/ticketflow/main/docs/screenshots/m2-agent-inbox.png)

- **Support workflows:** ticket creation, assignment, priorities, public replies, internal notes, and role-based dashboards.
- **Search and attachments:** Elasticsearch-powered public ticket search and private file storage with S3-compatible APIs.
- **Reliable processing:** transactional outbox and Hangfire jobs for notifications, reminders, escalations, and retries.
- **Frontend engineering:** generated OpenAPI client with TanStack Query, four languages, and right-to-left support for Persian.
- **Quality and delivery:** unit, integration, and Cypress browser tests, Docker Compose, and GitHub Actions.

**Stack:** Next.js, TypeScript, ASP.NET Core, PostgreSQL, Elasticsearch, Hangfire, S3-compatible storage, Docker.
